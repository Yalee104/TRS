TRS — Mini-Game Playground

A learning repo. Each card is a self-contained mini-game.

🥊

Arcade Fighter

Phaser 3 · Yuka AI · sprite atlas

1-v-1 fighting game vs. a Yuka-driven AI. Teaches the sprite pipeline, animation state machines, and the game loop.
🧩

Grid Path Puzzle

DOM/CSS + SVG · zero-dependency module

Drag a path from start to goal, weighing risk vs. reward. A reusable, framework-agnostic module with a configurable grid and node types.
✈️

Hack & Blast

Canvas 2D · embeds the puzzle as a "hack"

A vertical shooter where you open the grid-path puzzle to hack enemies (offensive) or shield yourself (defensive) — combos apply in slow-mo.
🛰️

TRS Command

DOM · turn-based strategy on the routing puzzle

Two component-built aircraft duel in alternating build→resolve phases. Solve a component's TRS to queue attacks/defenses; condition feeds firepower; destroy the enemy Reactor Core. (v1 battle loop.)
