🧪 TRS Puzzle Playground

Generates the exact TRS puzzle for a chosen phase + component, with live generation knobs — a tool to verify puzzles before they ship to the strategy game. Drag START 🚀 → GOAL 🏁; the order you cross skill icons builds the combo. A pre-start GO pause + START flash are toggleable.

Launch Pad (TRS quality)

Baseline (full HP)
Grid size & density exactly as the Generation panel — no modifier.
Damaged (≤50% HP)
Grid +1, blocker density +0.10 — bigger and more congested.
Destroyed (the cliff)
Grid +2, blocker density +0.20 — biggest and most congested, the hardest.

The blocker bonus layers on top of the Generation panel: e.g. Destroyed with the blocker slider at 0.40 paints at ≈0.60. Trap density is never modified by the pad.

Generation knobs

Payload count (min–max)
Exact number of payload icons, rolled in this range per board (no longer +1). Cluster on = the run sits together (easy to grab); off = spread along the route. Cleanse & Overclock require ≥3 chained — keep their min ≥ 3.
Require min chain (objective gate)
Optional win rule: the GOAL stays 🔒 locked until you've crossed at least Min chain matching payloads (badge pips fill, turn green when met). Reaching the goal early just prompts "Need X more" — it's blocked, not a fail. Capped at the payload-count min so it's always achievable. Off = reaching the goal always solves.
Placement
Where payloads sit vs. the high-value primary route. onPrimaryRoute: along the long intended route. lateOnRoute: pushed toward the goal end. offRoute: off the route — bait you must detour for (may be relaxed back onto the route on tight grids). anywhere: no constraint.
Link 🔗 (chain)
The amplifier that multiplies the combo (attack only). Appears % = chance the board includes it; placement = near End (reserved by the goal) or random on route.
Alternate routes
How many distinct shorter SAFE routes (carrying no payloads) the generator guarantees. 0 = only the payload route (forces the risk); 1+ = a low-risk / low-reward bypass exists.
Channeling
How hazards crowd the primary route. strong = blockers/traps biased to sit right beside the route (×1.6), funneling you onto it. soft = hazards spread evenly.
Primary length
Length of the intended (high-combo) route. long ≈ 1.6× the shortest path, medium ≈ 1.3×, short = the shortest. Longer = more room for icons but more hazard exposure.
Trap / Blocker density
Base chance an off-route cell becomes a trap (☠️ fails on entry) / blocker (⛔ impassable). Launch Pad shifts these.
